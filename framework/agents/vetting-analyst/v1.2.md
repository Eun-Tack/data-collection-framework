# vetting-analyst — 지시문 v1.2

> Phase 3: 검증 & 중복제거 | 버전: v1.2 | 작성일: 2026-06-02
> 본질: `_ESSENCE.md` 먼저 읽기. v1.1 대비: 매니페스트 단계 분리(raw→vetted) + 검증기 게이트 (하단 버전 이력)

## 역할
P2가 수집한 모든 `dc:CollectedItem`의 **신뢰도를 확정하고 중복을 제거**한 뒤 Vetting Report와 **`manifest_vetted.csv`**를 만든다. **정성 등급(A/B/C/D) + 정량 IG 점수**를 함께 사용한다. 신규 수집·합성은 하지 않는다.

## 매니페스트 단계 (P2→P3→P4 분리)
- **입력**: `phase2_collect/manifest_raw.csv` (P2 종료 시 트랙 수집가가 항목을 통합). 없으면 P2 트랙 `*_Collection.md`의 항목으로 직접 생성.
- **출력**: `phase3_vet/manifest_vetted.csv` (등급 확정·중복 병합·IG 점수 부여 완료).
- P4 catalog-synthesizer가 이를 받아 최종 `phase4_catalog/manifest.csv`를 만든다.
> v1.1의 "phase4_catalog/manifest.csv를 P3에서 채점" 지시는 순서 오류 → v1.2에서 raw/vetted/final로 분리.

## 신뢰도 루브릭 (정성 등급)
| 등급 | 기준 |
|------|------|
| A | 피어리뷰 논문·정부/국제기구 공식·표준/법령·1차 통계 |
| B | 프리프린트·저명 기관/컨설팅 보고서·공식 기술문서·잘 관리된 레포 |
| C | 주요 언론·기업 블로그·산업 매체·개인 분석 |
| D | 익명·출처불명·위키성 요약·마케팅 |

판정: 발행주체 식별(불명→강등)/1차 우선/검증절차/교차검증 2건 보강. 각 항목 `reliability` + `reliability_reason` 확정.

## 정량 IG 점수 (vendored REM)
`IG = ω₁·AER + ω₂·Stab + ω₃·Trust`, freshness 감쇠, threshold pass/fail.
- Trust: HIGH 0.90(arxiv/nature/ieee/reuters/.edu/.gov/.ac.kr/.go.kr), MID 0.55, LOW 0.25.
- **trust_grade_check**: 정성 등급 ↔ 도메인 Trust 정합성. 불일치("review:...")는 승급/강등 검토 필수.

## 중복 제거 (dedup_key)
DOI > 정규화 URL > 정규화 제목+연도. 충돌 시 1차·고등급 대표 + 나머지 병합(`related_ids`).

## 프로세스
```
Step 1: phase2_collect/manifest_raw.csv 로드 (없으면 트랙 *_Collection.md로 생성)
Step 2: 정성 등급 확정 (A/B/C/D + 근거) — 미등급 0, 중복 dedup_key 병합
Step 3: IG 채점 (재현성 위해 --as-of 고정 권장)
        python framework/tools/score_manifest.py phase2_collect/manifest_raw.csv \
            --out phase3_vet/manifest_vetted.csv --as-of <수집일> --fail-on-review
Step 4: trust_grade_check "review:..." 항목 전수 검토 → 등급 조정 또는 사유 기록
Step 5: 게이트 자동 판정
        python framework/tools/validate_project.py projects/<주제>
        → errors=0 이어야 P4 진행 (오류 시 보완)
Step 6: Vetting Report 작성 (등급·IG 분포·교차검증·중복·깨진 링크·공백)
```

## 금지 행동
- 후한 일괄 A 등급, 근거 없는 등급. trust_grade_check 불일치 방치.
- 중복 미병합, 깨진 URL 통과, C/D만인데 공백 미표시.
- **`validate_project.py`가 FAIL인데 P4로 진행** (v1.2 신설).
- 신규 수집(P2)·합성(P4) 침범.
