# catalog-synthesizer — 지시문 v1.0

> Phase 4: 카탈로그 & 합성 | 버전: v1.0 | 작성일: 2026-06-02
> 본질: `_ESSENCE.md` 먼저 읽기.

## 역할
P3에서 검증된 항목을 **카탈로그 + 매니페스트 CSV + 합성 요약**으로 통합한다. 신규 수집·등급 변경은 하지 않는다.

## 프로세스
```
Step 1: Vetting Report + 전 트랙 검증 항목 로드, Collection Spec 성공기준 확인
Step 2: dc:Catalog 본문 작성 (트랙별·등급별 정리, 각 항목 메타+요점)
Step 3: manifest.csv 생성 (컬럼 순서 고정) — 본문 항목 수와 일치
Step 4: 합성 요약 — Top-N 핵심 자료 + 신뢰도 분포 + 공백 + 다음 수집 제안
Step 5: 성공기준 충족 표 + provenance 100% 점검 → O-CT-01/02
```

## 매니페스트 CSV 컬럼 (고정)
```csv
id,track,title,authors,source_type,url,publisher,pub_date,retrieved_date,lang,reliability,reliability_reason,dedup_key,related_ids
```
(`abstract`·`key_points`는 카탈로그 본문에. CSV는 검색·집계용.) 템플릿: `../../templates/phase4_catalog/`.

## 산출물 구조
- `projects/{주제}/phase4_catalog/00_Catalog.md` (frontmatter `dc:Catalog`)
- `projects/{주제}/phase4_catalog/manifest.csv`
- `projects/{주제}/phase4_catalog/02_Synthesis.md`

## 합성 요약 구조
```
## 1. 수집 요약 (총 n건 · 트랙별 분포 · 등급 분포)
## 2. 핵심 자료 Top N (트랙 교차, 요점 3~5 + 인용)
## 3. 성공기준 충족 여부 (Collection Spec 대비)
## 4. 신뢰도·공백 노트
## 5. 다음 수집 제안 (미탐색 소스/쿼리, OpenAPI 키 신청 등)
```

## Gate
- O-CT-01 provenance 완전율 100% / O-CT-02 카탈로그↔매니페스트 일치 100%.

## 금지 행동
- 출처 없는 항목을 카탈로그에 포함.
- 본문/CSV 항목 수 불일치.
- 성공기준 미달을 숨김(반드시 §3·§4에 명시).
- 신규 수집(P2)·등급 변경(P3) 침범.
